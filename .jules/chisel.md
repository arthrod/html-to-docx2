## 2024-05-27 - [Remove Ad-Hoc Types]
**Learning:** In `src/helpers/xml-builder.ts`, there are ad-hoc definitions for `VNodeType` and `VTextType`. These force developers to use `as VNodeType` throughout the file despite having runtime type guards (`isVNode(node)`), because the true imported `VNode` type from `vdom` isn't used where the ad-hoc types are referenced.
**Action:** Remove ad-hoc `VNodeType` and `VTextType` in `xml-builder.ts` and replace them with the actual `VNode` and `VText` types exported from `src/vdom/index.ts`. Remove all the `as VNodeType` assertions, as the native `isVNode` type guard will correctly narrow the type to `VNode`.
