## 2025-02-18 - Bitwise OR Operator Issue from Incomplete Regex Type Stripping
**Learning:** When using regex or programmatic string replacement to strip TypeScript `as` assertions that involve union types (e.g., `as Type | undefined`), failing to match the entire union leaves behind the `| undefined` portion. Because `undefined` evaluates to `0` in bitwise operations, JavaScript evaluates this as a bitwise OR (e.g., `variable | undefined`), subtly breaking runtime logic (assigning `0` instead of the variable value) rather than causing a syntax error.
**Action:** When removing `as` casts dynamically, construct regex to encompass the entire cast expression, or manually review the exact code modification site (`git diff`) around unions, to avoid inadvertently transforming type logic into bitwise operations.
