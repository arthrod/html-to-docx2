## 2025-02-27 - [Type Signature Mismatch with Return Types]
**Learning:** When a function returns an input parameter directly (e.g., early return for a specific type branch), the parameter's type definition must be fully assignable to the function's declared return type. If a function returns `Record<string, string | null>`, typing the input parameter branch as `Record<string, unknown>` will cause a TypeScript error because `unknown` is not assignable to `string | null`.
**Action:** When typing input parameters that are passed through as return values, verify the return type compatibility of the fallback/pass-through branches before assigning broad types like `unknown`.
